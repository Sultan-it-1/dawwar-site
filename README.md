# Dawwar · دوّار — public site

The public pages for Dawwar, a file converter for Windows: the privacy policy that the Microsoft Store links to, and
later the landing page. GitHub Pages serves this repository (Settings → Pages → Deploy from a branch: `main`, `/`).

The source of these texts is the main (private) Dawwar repository: `docs/PRIVACY.md` and `docs/site/`. Change them
there first, then copy here.
